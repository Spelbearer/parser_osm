# Проверка реализации

Добавлен сбор набора федеральных округов с проверкой входных файлов/хешей/дат/replication timestamp/MD5, отдельными процессами на PBF, кэшем завершённых этапов, согласованием пересечений и единой региональной привязкой. Выход Teradata разбивается по регионам на CSV до 50 000 строк с `regions_index.csv`. Проверены кэш/повтор, безопасное сравнение полных снимков, отказ при конфликтующих версиях, блокировка неподтверждённого production, остановка процесса, вложенные автономные округа, конфликтующие границы и даталайн. На Linux с Python 3.11.17 и 3.13.5 проходят 125 тестов. Настоящие восемь PBF (4,15 ГБ по списку пользователя) находятся на его Windows-компьютере: общероссийский прогон, полнота 83 реальных полигонов и нагрузочные характеристики ещё не проверены.

Добавлен пакетный сбор локальных федеральных округов: предконтроль набора/хешей/дат/replication timestamp/MD5, один дочерний процесс на PBF, проверяемый кэш, единая пространственная привязка, выявление конфликтующих версий объектов и нормализация кандидатов границ. Региональные файлы Teradata разбиваются на части до 50 000 строк с каталогом `regions_index.csv`. Проверены повторное использование этапов, корректное сравнение полных снимков, сохранение предыдущего состояния при конфликте, блокировка боевого режима до подтверждений, остановка дочернего процесса и разбиение даталайн-полигона. На Linux с Python 3.11.17 и 3.13.5 проходят 122 теста. Реальные 8 PBF пользователя находятся на его Windows-компьютере: общероссийский прогон, 83 реальных полигона, память/диск/время на них в облаке не проверялись.

Relation исключены из итоговых файлов Teradata выходным профилем `teradata_osm_types=[node,way]`. Полный реестр и общий экспорт сохранены. Проверены CSV/Parquet, случай источника только с relations (корректный пустой TD-файл), счётчики исключений, явное восстановление relation в профиле и отклонение некорректных настроек. 114 тестов проходят на Linux с Python 3.11.17 и 3.13.5.

Для Teradata добавлен выбор одной основной категории с приоритетом телефонии и отдельные `poi_teradata.csv/parquet`. Проверены согласованные комбинации тегов, приоритет ремонта телефонов, детерминированность при перестановке строк, пользовательский порядок, сохранение `all_tags`, фактическая уникальность CSV/Parquet и смена приоритета при неизменном ключе объекта. SQL-пример обновлён на `(OSM_TYPE, OSM_ID)` без категории в ключе. 108 тестов проходят на Linux с Python 3.11.17 и 3.13.5; SQL в Teradata не исполнялся.

Добавлен основной экспорт одной строки на `(osm_type, osm_id)`: все категории сохраняются в объединённых полях и JSON `classifications`. Подробные строки и внутренний реестр по тегам сохранены. Проверены коллизии числовых ID между node/way, несколько категорий, объединение признака телефонии, конфликтные сети, противоречащие координаты, CSV/Parquet и read-only преобразование готовой выгрузки без PBF. На Python 3.11.17 и 3.13.5 под Linux проходят 95 тестов.

Телефония расширена косвенными направлениями `electronics`, `electronics_repair`, `computer`, `repair`. Все правила включения и подписи вынесены в `config/telecom.json`; общие категории остаются в `config/categories.json`. Проверки дополнены включением без признаков в названии, изменением состава/подписей через JSON, пользовательским путём файла и валидацией пересекающихся списков.

Для адресной программы добавлены бизнес-категории, телефония и справочник 35 сетей, расширены пары OSM для ПВЗ и ремонта. **81 тест прошёл на Linux с Python 3.11.17 и 3.13.5**: в том числе чтение настоящего тестового PBF с `brand` и признаками ремонта, CSV/Parquet с boolean/null, нормализация названий сетей, конфликтные марки, пользовательские справочники и защита старого реестра от несовместимого сравнения. Полнота сетей и классификация реальных организаций не проверялись внешним бизнес-реестром; совпадения названий требуют проверки. SQL-пример Teradata дополнен новыми полями, но на СУБД не исполнялся.

Обновление совместимости Windows: после пользовательского отчёта о WinError 32 и неверной кодировке pipe исправлены очистка временных индексов и UTF-8 вывод CLI. Индексы вынесены за пределы атомарно публикуемого каталога; при sharing violation они остаются до освобождения процессом и удаляются следующим запуском. Регрессионный тест моделирует блокировку файла и cp1251, проверяя успешную публикацию и последующую очистку. После исправлений: **51 тест прошёл на Linux с Python 3.11.17 и 3.13.5**. Нативный Windows-запуск здесь не выполнен; добавлена матрица GitHub Actions Windows/Linux × Python 3.11/3.13.

Дата: 2026-11-10. Среда: Linux x86_64, CPython 3.11.17. Версии зависимостей закреплены в requirements*.txt.

Тесты используют настоящие небольшие PBF с искусственными геометриями. Проверены смена снимков и категорий, все четыре статуса, сохранение first_seen при возвращении записи, типовые и пространственные дубли, раздельные региональные состояния, парсинг node/way/relation, внутренняя точка вогнутого полигона и антимеридиан. Также проверены контрольные суммы, давность, повторные попытки загрузки через HTTP-дубли, сохранение предыдущей версии при сбоях и аномалиях, блокировка второго процесса, read-only режим --check, CSV с BOM/экранированием/переносами и Parquet с DATE/null и фильтрацией региона.

Производственный `main.py --check` ожидаемо вернул exit 1: нет проверенного `boundaries/regions.geojson`, `boundaries_reviewed=false`, источник Geofabrik недоступен через сетевой прокси (403 на CONNECT). Проверка актуальной даты/размера/условий источника и реального региона не выполнена. Измеренные 0.1 секунды демонстрационного запуска неприменимы к оценке России.

Не проверялись: полноценная выгрузка России, реальные региональные границы, производительность на полном PBF, Windows и работа Планировщика, исполнение SQL в Teradata. Тесты HTTP используют воспроизводимые ответы, а не подтверждают доступность реального издателя.

Сохранение полей install_script/start_skill облачной конфигурации завершилось ошибкой INVALID_ARGUMENT; платформа не подтвердила сохранение. Инструкции доступны локально в scripts/cloud_install.sh и docs/cloud-start.md. Публикация облачной среды не выполнялась.
