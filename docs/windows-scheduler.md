# Планировщик Windows

Сначала выполните успешный ручной запуск через `run.py`. Для расписания используйте тот же Python виртуального окружения и ту же корневую папку результата.

В Планировщике заданий:

- Программа: `D:\parser\parser_osm\.venv\Scripts\python.exe`.
- Аргументы: `"D:\parser\parser_osm\run.py" --root "D:\osm_results"`.
- Рабочая папка: `D:\parser\parser_osm`.
- Триггер: например, первый день месяца в 02:00 по часовому поясу компьютера.
- При уже запущенной задаче: не запускать новый экземпляр.
- Включите запуск пропущенной задачи при первой возможности. Ограничение длительности выбирайте по измеренному полному запуску.

До запуска новый согласованный комплект восьми PBF должен находиться во входной папке из `product.json`. Одновременно несколько дат одного округа не оставляйте. Устаревшие, смешанные или неполные наборы блокируют обновление.

Код завершения 0 означает успех; ненулевой — ошибку или отмену. Смотрите `logs/` и `result/analysis/summary.json`. При неудаче предыдущий результат сохраняется. Для пересборки только файлов используйте аргумент `--files`.

При запуске без окна можно выбрать `pythonw.exe` с тем же `run.py`; отдельной копии скрипта не требуется. Учётная запись должна иметь доступ к PBF, конфигурации и папке вывода. Приложение не регистрирует задачу автоматически. Работу Планировщика проверяют на целевом Windows-компьютере.
