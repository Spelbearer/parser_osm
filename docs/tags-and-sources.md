# Категории и происхождение данных

## Правила отбора

`config/tag_mapping.json` сопоставляет целевое **значение** одному или нескольким разрешённым **ключам** OSM. Например, `hotel: ["tourism"]` означает `tourism=hotel`; слово `hotel` в `name` или `note` не является категорией. Объект может дать несколько категорий. Для одной категории совпадение нескольких допустимых ключей не должно создавать несколько строк по одному `(osm_type, osm_id, tag)`.

Исходный набор из 50 значений расширен для адресной программы: включён `shop=outpost` для ПВЗ, добавлены `amenity=parcel_locker`, `shop=mobile_phone_repair`, `shop/office=telecommunication`, `shop=telecom`, `shop/craft=electronics_repair`, `shop=repair`, `repair=mobile_phone`. Четыре значения остаются выключенными: `commercial`, `food`, `retail`, `coffee` (`[]` в JSON). Они не заменены похожими словами или `amenity=cafe`/`amenity=post_office`. Например, `landuse=commercial` описывает землепользование, а не обязательно отдельное торговое заведение. Дополнительные точные пары покрывают разные варианты разметки; актуальная распространённость каждой пары не измерялась, а отсутствие подходящих тегов в OSM может оставить реальный бизнес вне выгрузки.

Остальные 45 включены с точным совпадением значения. По умолчанию используется `shop`; исключения и дополнения:

| Значение | Разрешённые ключи |
|---|---|
| `hotel` | `tourism` |
| `fitness_centre` | `leisure` |
| `tailor` | `shop`, `craft` |
| `photographer` | `craft`, `shop` |
| `locksmith` | `craft`, `shop` |
| `photographic_laboratory` | `craft`, `shop` |
| `ice_cream` | `shop`, `amenity` |

Справочные страницы: [Key:shop](https://wiki.openstreetmap.org/wiki/Key:shop), [Key:craft](https://wiki.openstreetmap.org/wiki/Key:craft), [tourism=hotel](https://wiki.openstreetmap.org/wiki/Tag:tourism%3Dhotel), [leisure=fitness_centre](https://wiki.openstreetmap.org/wiki/Tag:leisure%3Dfitness_centre), [amenity=ice_cream](https://wiki.openstreetmap.org/wiki/Tag:amenity%3Dice_cream). Эти ссылки фиксируют, что нужно проверять, но не являются заявлением об успешной сетевой проверке. Во время разработки запросы к OSM Wiki и Geofabrik получили `403` от прокси среды; актуальное содержимое не прочитано. Перед производственной приёмкой сопоставления следует сверить с Wiki и фактическими данными. Включённые пары, особенно редкие/устаревшие `shop=*` для ремёсел, не следует считать официальной рекомендацией OSM.

Исходное значение сохраняется в `osm_value`, исходный выбранный ключ — в `osm_key`. Произвольное сопоставление по всем тегам и замена на семантически близкие категории запрещены. Отсутствующее название сохраняется как NULL, искусственное название не генерируется. Приоритет `name`/`name:ru` задаётся конфигурацией.

## PBF и лицензия

Основной кандидат источника: [Geofabrik Russia](https://download.geofabrik.de/russia.html). Конкретный рабочий URL PBF и URL контрольной суммы задаются в `settings.json`; не нужно считать URL гарантированным только по имени. Смотрите фактический результат `--check`. Для полного снимка нужен provenance, дата актуальности и согласованный `coverage_id`; региональная выгрузка не заменяет полный общероссийский снимок.

Нельзя использовать публичный Overpass для массовой выгрузки всех POI России. Резервный источник должен быть явно настроен, документирован и иметь тот же согласованный охват. Случайный найденный PBF без сведений о происхождении и целостности не является корректным резервом.

Контрольная сумма издателя проверяет целостность загрузки; MD5, если именно его публикует Geofabrik, не является криптографическим доказательством авторства. Происхождение обеспечивается HTTPS с проверкой сертификата и доверенным URL источника, дополнительно рассчитывается SHA-256 локального файла. Дата файла не должна подменяться текущей датой запуска. Источники старше разрешённого порога не должны публиковаться как свежие.

Данные OSM распространяются по [Open Database License (ODbL)](https://www.openstreetmap.org/copyright). При использовании и распространении выгрузок указывайте `© OpenStreetMap contributors`, ссылку на OSM и ODbL; применимость share-alike зависит от способа распространения производной базы. Для источника границ отдельно зафиксируйте лицензию и атрибуцию. Условия Geofabrik следует проверить на сайте перед регулярной массовой загрузкой; актуальная страница условий из этой среды не была доступна.

Для сетевой проверки в настройках среды нужны разрешения как минимум на `download.geofabrik.de`, `wiki.openstreetmap.org`; для проверки лицензии также `www.openstreetmap.org`, для справочника кодов `www.iso.org`. Если источник перенаправляет на другой хост, добавьте именно проверенный адрес перенаправления. Не отключайте TLS или проверки суммы, чтобы обойти ограничения.
